# Entrega de Handoff Técnico

## Arquivos principais
- `index.html`: estrutura da tela
- `styles.css`: todos os estilos extraídos do monólito
- `script.js`: toda a lógica JavaScript extraída do monólito
- `HANDOFF_TECNICO.md`: documentação oficial completa para desenvolvimento

## Como abrir
1. Abra `index.html` no navegador.
2. Garanta que `styles.css` e `script.js` estejam na mesma pasta.

## Observação
Esta pasta preserva o comportamento atual da versão monolítica, mas já separada para facilitar manutenção e evolução.
